# 🏆 피클 프로젝트 투표 앱

AI파이썬랩 심화 11주차 「나만의 서비스 발표회」에서 쓰는 Streamlit 투표 웹앱입니다.

## 구조

- 반마다 **발표회** 하나를 만듭니다. 발표회를 만들면 **입장 코드**(4자리)가 자동으로 생깁니다.
- 학생은 입장 코드(또는 QR)로 들어와 **명단에서 자기 이름을 고르면** 끝입니다. PIN은 없습니다.
- 발표회는 `준비 → 프로젝트 등록 → 투표 → 결과 공개` 순서로 한 단계씩 진행합니다.

## 사용 흐름

**선생님**: 🔐 선생님 메뉴 → 사이드바 `➕ 새 발표회 만들기`에서 이름과 학생 명단(한 줄에 한 명)을 넣고 만들기 → `▶️ 진행` 탭의 입장 코드·QR을 화면에 띄우기(`📺 크게 띄우기`) → 수업 흐름에 맞춰 `▶ 다음 단계` 버튼 누르기

**학생**: QR을 찍거나 코드를 넣기 → 이름 고르기 → 단계에 맞는 화면 하나만 보입니다.

| 단계 | 학생 화면 |
|---|---|
| 준비 | 기다리기 (선생님이 단계를 넘기면 5초 안에 화면이 저절로 바뀜) |
| 프로젝트 등록 | 프로젝트 이름, 만든 이유, 기능 설명, 배포한 URL 등록·수정·삭제 |
| 투표 | 친구 프로젝트 카드(앱 열어 보기) + 세 부문(써 보고 싶은 / 아이디어 / 완성도)에 한 명씩 + 고른 이유 한 줄. 다시 제출하면 덮어씀 |
| 결과 공개 | 종합 순위·부문별 순위(표 수 없이), 내가 받은 한마디(본인 것만) |

**선생님 모드 탭**

| 탭 | 하는 일 |
|---|---|
| ▶️ 진행 | 단계 버튼, 입장 코드·QR·주소, 학생별 등록·투표 현황(5초마다 새로고침), 프로젝트 카드(언제든 수정·삭제) |
| 🏆 결과 | 결과 미리보기. `선생님만 볼 정보 보이기`를 켜면 표 수와 모든 학생의 한마디. 끄면 교실 화면에 그대로 띄울 수 있음 |
| ⚙️ 관리 | 명단 추가·학생 삭제, 백업(JSON), 발표회 삭제 |

## 보안과 데이터 보관

- 학생은 입장 코드 + 이름으로만 들어옵니다. 선생님이 지켜보는 수업 안에서 쓰는 것을 전제로 합니다.
- 1분 안에 틀린 입장 코드가 20번 넘게 들어오면 잠시 막습니다(코드 맞히기 방지). 선생님 비밀번호는 10번 틀리면 1분 동안 잠깁니다.
- 삭제는 학생 삭제(프로젝트·투표 포함)와 발표회 삭제 두 가지뿐입니다. 학생은 등록 단계에서 자기 프로젝트만 지울 수 있습니다.
- **만든 지 90일이 지난 발표회는 자동으로 지워집니다** (선생님이 들어올 때 확인).
- 예전 형식(학기·수업·시간대 반 + 학생 PIN) 데이터는 앱이 처음 읽을 때 발표회로 자동 변환되고, PIN 정보는 지워집니다.

## 데이터 저장

모든 데이터는 JSON 파일 하나(`vote_data.json`)에 모입니다.

- **로컬 실행**: `data/vote_data.json`
- **Streamlit Cloud**: 비공개 저장소 `jay-pickle/pickle-vote-data` 의 `vote_data.json`
  (Streamlit Cloud 는 앱이 잠들거나 재시작되면 로컬 파일이 지워지기 때문)

## 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

`ADMIN_PASSWORD` 가 없으면 내 컴퓨터(localhost)에서만 테스트용 비밀번호 `dlab` 이 동작하고, 배포 환경에서는 선생님 메뉴가 꺼집니다.

## Streamlit Cloud secrets

```toml
ADMIN_PASSWORD = "선생님 비밀번호"

[github]
token = "github_pat_..."          # pickle-vote-data 에 Contents 읽기/쓰기 권한만 준 fine-grained 토큰
repo = "jay-pickle/pickle-vote-data"
path = "vote_data.json"
branch = "main"
```
