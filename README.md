# 🏆 피클 프로젝트 투표 앱

AI파이썬랩 심화 11주차 「나만의 서비스 발표회」에서 쓰는 Streamlit 투표 웹앱입니다.

## 구조

- **학기** (예: 26여름, 26가을, 27봄): 최신 학기부터 (연도 → 봄·여름·가을·겨울 내림차순)
- **수업** (예: AI파이썬랩 기본, AI파이썬랩 심화): 가나다/알파벳 오름차순
- **시간대** (예: 토/0900, 토/1100, 수/1930): 가나다/알파벳 오름차순
- 학기 + 수업 + 시간대 = **반**. 학생은 자기 반을 고르고 그 반 안에서만 등록·투표합니다.

## 사용 흐름

**선생님 준비**: 🔐 선생님 메뉴로 들어가 ➕ 새 반 탭에서 반을 만들고, 👥 학생 명단 탭에 이름(한 줄에 한 명)을 넣은 뒤, 🔗 학생 주소 탭의 주소를 나눠 줍니다.

**학생**
1. 주소로 접속 → **로그인** 칸에서 수업·시간대를 고르고(반별 주소로 오면 미리 채워짐) 이름과 PIN 입력
   - 처음이면 "처음이에요 (PIN 정하기)"에서 명단에 있는 내 이름으로 PIN 4자리를 정함
   - 다음부터 "들어가기"에서 이름 + PIN
   - 로그인하기 전에는 다른 화면이 보이지 않고, 로그인하면 그 반으로 고정 (다른 반은 나가기 후 다시 로그인)
2. 탭에서 등록·보기·투표·결과

| 탭 | 하는 일 |
|---|---|
| 📝 프로젝트 등록 | 프로젝트 이름, 만든 이유, 기능 설명, 배포한 URL 입력. 다시 제출하면 수정, 아래 '내 프로젝트 삭제'로 삭제 |
| 🔍 프로젝트 보기 | 반 친구들의 프로젝트 카드와 앱 바로가기. **내 카드에만** ✏️ 수정 · 🗑️ 삭제 버튼 |
| 🗳️ 투표하기 | 세 부문(써 보고 싶은 / 아이디어 / 완성도)마다 친구 프로젝트 하나 + 고른 이유. 내 프로젝트는 목록에 없고, 다시 제출하면 새 투표로 바뀜. 프로젝트가 없어도 투표 가능 |
| 🏆 결과 보기 | 투표 진행 현황, 선생님이 공개하면 종합 순위·부문별 순위·내가 받은 한마디(본인 것만). 학생 화면에는 순위만 보이고 표 수는 선생님 화면에만 보임 |

**선생님 모드** (🔐 선생님 메뉴에 `ADMIN_PASSWORD`): 사이드바에서 모든 학기의 반을 고르고 아래 탭을 씁니다.

| 탭 | 하는 일 |
|---|---|
| 🔍 프로젝트 보기 | 모든 카드 수정·삭제 가능 (등록이 닫혀 있어도) |
| 🏆 결과 보기 | 공개 전 미리보기, 모든 학생의 한마디 |
| 👥 학생 명단 | 이름 추가, 학생별 PIN·프로젝트·투표 현황, PIN 바꾸기·지우기 |
| 🔗 학생 주소 | 로그인 칸에 반이 미리 채워지는 주소 |
| 🎛️ 진행 단계 | 등록·투표·결과 공개 켜고 끄기 |
| 🧹 정리 | 이 반의 프로젝트·학생·투표를 여러 개 골라 삭제, 투표 초기화 / 모든 학기 반 목록에서 반 골라 삭제·학기 통째로 삭제 / **앱 전체 데이터 삭제** (확인 문구 '전체 삭제' + 선생님 비밀번호 필요) |
| ➕ 새 반 | 학기·수업·시간대로 반 만들기 |
| 💾 백업 | 전체 데이터 JSON 내려받기 |

## 보안

- 선생님 명단에 있는 이름만 PIN을 정하고 로그인할 수 있습니다. 로그인 전에는 반 내용이 보이지 않습니다.
- 학생 PIN은 해시(PBKDF2)로만 저장하고, 5번 틀리면 그 학생은 5분 동안 잠깁니다. 선생님은 🧹 정리 탭에서 새 PIN으로 바꾸거나 PIN을 지워 학생이 다시 정하게 할 수 있고, 이때 잠금도 풀립니다.
- 선생님 비밀번호는 10번 틀리면 1분 동안 잠깁니다.
- 삭제 권한: 선생님은 모든 데이터, 학생은 자기 프로젝트만 (프로젝트 등록이 열려 있을 때). 서버에서도 한 번 더 확인합니다.

## 데이터 저장

모든 데이터는 JSON 파일 하나(`vote_data.json`)에 모입니다.

- **로컬 실행**: `data/vote_data.json`
- **Streamlit Cloud**: 비공개 저장소 `jay-pickle/pickle-vote-data` 의 `vote_data.json`
  (Streamlit Cloud 는 앱이 잠들거나 재시작되면 로컬 파일이 지워지기 때문)

## 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

`ADMIN_PASSWORD` 가 없으면 내 컴퓨터(localhost)에서만 테스트용 비밀번호 `dlab` 이 동작하고, 배포 환경에서는 선생님 메뉴가 꺼집니다.

## Streamlit Cloud secrets

```toml
ADMIN_PASSWORD = "선생님 비밀번호"

[github]
token = "github_pat_..."          # pickle-vote-data 에 Contents 읽기/쓰기 권한만 준 fine-grained 토큰
repo = "jay-pickle/pickle-vote-data"
path = "vote_data.json"
branch = "main"
```
